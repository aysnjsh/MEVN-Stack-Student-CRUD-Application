# Screen recording guide

Start MongoDB and run `npm run dev`. Open http://localhost:8080. Use made-up student records; do not show your `.env` or database password while recording.

1. **Create Student:** Show the navigation and form. Enter `Juan Dela Cruz`, `juan@example.com`, and `639171234567`. Click Create Student.
2. **View Students:** Show the new record in the directory. Refresh the browser to demonstrate that it remains saved in MongoDB.
3. **Edit Student:** Click Edit, change the name to `Juan Miguel Dela Cruz`, and click Save Changes. Show the updated record.
4. **Search:** Type `Juan` in the search field. Clear the search afterward.
5. **Delete Student:** Click Delete, show the confirmation, and confirm. Show that the record is removed.
6. **My Profile:** Show your actual photo, full name, degree, specialization, email, and residence.

Optional: briefly show validation by trying to submit a blank form or an invalid email. Keep the main focus on the working CRUD operations.

The instructor asks for a screen recording; the supplied guidelines do not explicitly require narration or a webcam. A clear 2–4 minute recording is a suggested length, not a stated requirement.

Save as `Demo.mp4` and add it to the final submission ZIP. The source ZIP provided with this project does not include a student-recorded demonstration.
