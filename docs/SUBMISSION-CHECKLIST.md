# Submission checklist

- [ ] Own MongoDB Atlas connection configured and working.
- [ ] Create a record successfully.
- [ ] View saved records and confirm they remain after refresh/restart.
- [ ] Edit a record successfully.
- [ ] Delete a record successfully.
- [ ] Check invalid input and readable error feedback.
- [ ] Profile contains actual full name and photo.
- [ ] Profile contains degree and specialization.
- [ ] Profile contains actual email and complete barangay/city/province.
- [ ] Public GitHub repository contains the source files.
- [ ] `GitHub-Link.txt` contains the actual public repository URL.
- [ ] Screen recording demonstrates all pages and CRUD operations.
- [ ] Final ZIP contains source files, link text file, and recording.
- [ ] Final ZIP excludes `node_modules`, `.git`, and real `.env` credentials.
- [ ] Submit to the assignment file-upload page.

The linked tutorial also includes deployment; see DEPLOYMENT.md. The quoted assignment submission list does not separately request a hosted URL.
